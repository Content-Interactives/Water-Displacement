# Water Displacement Interactive (v2)

React single-page app for a water displacement / volume lesson. Curriculum alignment is documented in [Standards.md](Standards.md).

**Live:** https://content-interactives.github.io/water_displacement_v2/

(`package.json` sets `homepage` to `https://content-interactives.github.io/Water-Displacement` for Create React App asset paths—keep that consistent with your GitHub Pages project URL.)

## Requirements

- Node.js 18+ recommended  
- npm

## Commands

| Command | Description |
|---------|-------------|
| `npm install` | Install dependencies |
| `npm start` | Dev server (react-scripts) |
| `npm run build` | Production build → `build/` |
| `npm test` | Jest / Testing Library test runner |
| `npm run deploy` | `predeploy` build, then `gh-pages -d build` |

## Stack

- React 19  
- Create React App (`react-scripts` 5.x)  
- gh-pages for static hosting

## Layout

- `public/` — static assets and `index.html` shell  
- `src/` — application source (`App`, components, styles)  
- `build/` — generated by `npm run build` (not committed)
